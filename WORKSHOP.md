# Workshop page text: While You're Up (rimhunter)

Paste into the Workshop description when uploading. Agents never post on Steam.

---

Opportunistic hauling for RimWorld 1.6 and 1.7: your colonists pick up items that lie on the way to a job, and haul supplies closer before building or crafting. Haul-to-inventory improvements are added if Pick Up And Haul is installed (the improvements apply to Mehni's original and Continued; Pick Up And Haul - Reworked already does these itself, so this mod leaves it alone). Compatible with existing saves. Any load order. Your settings from the original mod are copied over the first time you launch this one.

Continuation of "While You're Up" by Christopher "CodeOptimist" Galpin: https://steamcommunity.com/sharedfiles/filedetails/?id=2034960453 (source: https://github.com/CodeOptimist/rimworld-while-youre-up). ## Unsubscribe from these first

Do not run two copies. Unsubscribe from, or disable, each of these before you use this mod:

- "While You're Up" by CodeOptimist (the original, Workshop id 2034960453, package `CodeOptimist.JobsOfOpportunity`)
- "While You're Up (1.6 patch)" (package `zsbk.patch16.whileyoureup`)
- "While you're up 1.7" (package `hoodie.whileyoureup`)
- The older "While You're Up" by kevlou and its continuation (package `kevlou127.WhileHYouOreHUpHQ1V0S`)

RimWorld's mod list warns you when any of these is enabled together with this mod.
